首次使用：连接你的 GitHub

这个后台通过 GitHub 保存修改，需要你创建一个一次性的访问令牌（只对你的网站仓库有效，可随时撤销）。

  1. 打开 github.com/settings/personal-access-tokens/new（没登录先登录）
  2. Token name 随便填，比如 felixseo-admin
  3. Expiration 选 No expiration
  4. Repository access 选 Only select repositories → 只勾选 felixseo-site
  5. 展开 Repository permissions，把 Contents 设为 Read and write，其他全部不动
  6. 点最下方 Generate token，把生成的 github_pat_ 开头的令牌粘贴到下面

令牌只保存在你自己的浏览器里（localStorage），不会上传到任何服务器。换电脑/清浏览器后需要重新粘贴一次。
